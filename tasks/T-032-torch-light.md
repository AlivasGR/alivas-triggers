# T-032 — Torch: lit torches shed light, held or dropped

- **Status:** done
- **Foundry:** test
- **Owner:** Alivas
- **Area:** box

## Goal
A 2024 Torch can be lit. While lit, whoever holds it (a creature, or a loot pile on the ground) sheds Bright Light
20 ft and Dim Light 20 ft more, for 1 hour. Built from the Engine's existing item light rule (the one Sacred Weapon
uses), with no engine changes.

## Sources
- 2024 PHB p. 229: 5etools `items.json` "Torch|XPHB" (burns 1 hour; Bright Light 20 ft and Dim Light 20 ft more;
  as a Simple Melee weapon, 1 Fire damage).
- dnd5e 6.1.x `packs/_source/equipment24/adventuring-gear/torch.yml` (`phbagTorch000000`: consumable, trinket,
  identifier `torch`, an attack activity).

## Done
`alivas-box-of-triggers/packs/_source/fixed-items/torch-phb-2024-229.json`, v1. Matches type consumable, identifier
`torch`, PHB 2024 or the dnd5e SRD copy.
- **Light** (Bonus Action): an enchant activity with `enchant.self`, so it lights its own torch. It applies **Lit**, an
  enchantment lasting 1 hour that adds "(lit)" to the name and carries the Engine flag
  `light: { bright: 20, dim: 40, color: "#ff9b3d", animation: "torch" }`.
- **Attack:** 1 Fire damage, Str. `keep.activities: ["attack"]` keeps the target's own attack if it has one.
- **Douse:** delete the applied Lit effect on the item (item sheet, Effects).

Generated by the same script as T-030/T-031.

Checks:
- (offline) `strip-rules-text --check` passes; `npm run pack` builds.
- (live 2026-11-26, Foundry 14.370 / dnd5e 6.1.1):
  - The patch applies on creation.
  - **Light:** the holder's token goes from 0 to 20 / 40, colour `#ff9b3d`, torch animation; the item reads
    "Torch(lit)".
  - **Hand-over:** the lit torch copied to another actor and removed from the first; the light moves with it.
  - **Douse:** deleting the applied Lit puts the light back to 0.
  - **Dropped:** the lit torch moved into an unlinked token's actor (what an Item Piles pile is) lights that token
    20 / 40; the old holder goes dark.
  - **Burn-out:** after 3,601 s of game time the enchantment is gone and the light is off.

## Left
- A burnt-out torch stays in the inventory and can be relit: remove or reduce it by hand (the 1-hour use isn't
  consumed).
- Lighting a stack (quantity above 1) lights the whole stack as one light source. Split one off first.
- The name shows "Torch(lit)": Foundry trims the leading space of the name change.
